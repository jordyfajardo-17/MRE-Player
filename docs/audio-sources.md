# Fuentes de audio de la segunda iteración

Audius sigue disponible. Se añade Archivo abierto, basado en la búsqueda y metadata oficiales de Internet Archive. Funciona sin claves y mantiene IDs, atribución, licencia y enlaces de origen. El catálogo está limitado a items de audio musical con declaración CC0 o CC BY 4.0; no se asume que el archivo completo sea de dominio público. Se reproducen archivos MP3 públicos y se conserva una sola representación por archivo original. No se descarga audio para uso offline.

Las consultas se cancelan al cambiar la búsqueda, tienen tiempos límite y limitan a tres solicitudes concurrentes de metadata. Cada página explora seis items. Los resultados de ambas fuentes se intercalan y se eliminan duplicados por ID estable. Un proveedor fallido se muestra como aviso mientras el otro conserva sus resultados.

Jamendo se evaluó como alternativa de música independiente con streams y búsqueda: requiere registrar una aplicación y obtener un client_id propio. Sus términos distinguen uso no comercial del comercial. No se incorporan IDs ajenos ni se prometen permisos comerciales para MRE. Spotify, YouTube y Apple permanecen pendientes, según la decisión del proyecto.
